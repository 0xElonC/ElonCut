# ElonCut operation manual

Purpose, how to read this embedded manual, and capabilities not yet covered.

This manual helps an editing agent choose ElonCut tools and understand their
limits. It is embedded in the MCP server and read with `guide_read`; it is not
installed as a skill on the person's machine or copied into their project.

Call `guide_read` without arguments to list topic ids and one-line summaries.
Pass a topic id as the `topic` argument to read that topic. Start here before
editing, then read the topics relevant to the person's request.

## Not yet covered

This initial index is a placeholder. Detailed editing workflows, titles and
captions, effects, filters, transitions, keyframes, masks, shapes, templates,
export and verification will be documented in subsequent topics. Absence from
this manual does not establish whether an API capability exists: inspect the
tool catalogue and its argument schemas; tell the person when a requested
capability is unavailable rather than inventing a tool or result.
